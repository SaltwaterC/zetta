# Gong recording

`gong.pcm` is a processed excerpt of “Chinese Gong Finish Session,” recorded
by Freesound user the_very_real_horst and released under CC0 1.0. The original
is available from [Wikimedia Commons][source].

The first strike was mixed to mono, trimmed to 4.2 seconds, denoised, filtered
to 35–8000 Hz, faded at both boundaries, and resampled to 22050 Hz. It is stored
as headerless signed 16-bit little-endian PCM so that the quiet metallic tail
does not acquire the quantization crackle caused by companded 8-bit audio.
Zetta decodes and resamples it during playback.

[source]: https://commons.wikimedia.org/wiki/File:240382_the-very-real-horst_chinese-gong-finish-session-2014-06-10-29-143.wav
