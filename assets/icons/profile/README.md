# Zetta profile icons

The Zetta, Bash, Zsh, and Fish icons are original artwork created for Zetta
and are distributed under the same GPL-3.0-or-later license as the application.
The Tux icon is copied from [Windows Terminal's WSL profile-generator
asset](https://github.com/microsoft/terminal/blob/main/src/cascadia/CascadiaPackage/ProfileGeneratorIcons/WSL.png),
which is distributed by that project under the [MIT
license](https://github.com/microsoft/terminal/blob/main/LICENSE). Copyright
(c) Microsoft Corporation. All rights reserved. It is used as a generic
Linux/WSL mark and does not identify the shell running inside a distribution.

The SVG files are the source artwork for Zetta's icons, and `tux.png` is the
upstream Tux artwork. The Windows `.ico` files are generated from the
corresponding artwork and are embedded in `zetta-gui.exe` for Jump List
entries.
