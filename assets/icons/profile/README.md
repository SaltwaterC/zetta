# Zetta profile icons

These four small icons are original artwork created for Zetta and are
distributed under the same GPL-3.0-or-later license as the application. They
are simplified terminal-profile marks, not the official logos of Bash, Zsh, or
Fish. The names identify the shell represented by each icon; no shell project
endorses Zetta.

The SVG files are the source artwork. The Windows `.ico` files are generated
from those SVGs and are embedded in `zetta-gui.exe` for Jump List entries.
